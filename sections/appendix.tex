\subsection{目标函数计算}
以下代码展示式~\eqref{eq:objectives}中两个目标的计算方式。
输入应使用实际材料数据；完整求解程序可用模板的 \verb|\codefile| 命令引入。

\begin{lstlisting}[language=Python]
def objectives(masses, carbon_factors, prices):
    if not (len(masses) == len(carbon_factors) == len(prices)):
        raise ValueError("Input lengths must match")
    carbon = sum(m * e for m, e in zip(masses, carbon_factors))
    cost = sum(m * c for m, c in zip(masses, prices))
    return carbon, cost
\end{lstlisting}
