\section{核心算法程序}
\label{app:code}
以下程序复现附录~\ref{app:data}的合成数据结果，仅展示目标计算和非支配解筛选，
不构成完整的 NSGA-II；交叉、变异、拥挤度与约束处理等应在实际求解时补充。

\subsection{Python：目标计算}
\begin{lstlisting}[language=Python]
def objectives(x, e, c):
    return tuple(sum(m * f for m, f in zip(x, factors))
                 for factors in (e, c))

X = [(300, 80, 5), (280, 100, 8),
     (260, 120, 10), (300, 100, 10)]
e, c = (0.9, 0.1, 0.2), (0.4, 0.8, 0.5)
F = [objectives(x, e, c) for x in X]
print("Objectives:", F)
\end{lstlisting}

\subsection{Python：非支配解筛选}
以下代码接续上例，输出方案编号 \texttt{[1, 2, 3]}。
\begin{lstlisting}[language=Python]
def dominates(p, q):
    return (all(a <= b for a, b in zip(p, q))
            and any(a < b for a, b in zip(p, q)))

front = [i + 1 for i, point in enumerate(F)
         if not any(dominates(other, point) for other in F)]
print("First front:", front)
\end{lstlisting}

\subsection{MATLAB：向量化复核}
将各方案按行组成矩阵 \texttt{X}，传入同一组 \texttt{e}、\texttt{c}，
所得矩阵两列依次为碳排与成本。
\begin{lstlisting}[language=Matlab]
function F = objectives_matlab(X, e, c)
    % Evaluate both objectives for all candidates.
    F = [X * e(:), X * c(:)];
end
\end{lstlisting}
