# 版式与使用说明

## 当前默认值

| 项目 | 默认设置 | 依据 |
| --- | --- | --- |
| 纸张 | A4 | 两个参考项目 |
| 页边距 | 上 30 mm，下 25 mm，左右 22.5 mm | 两个参考项目的 geometry 设置 |
| 正文 | 中文小四，首行缩进 2 字，行距因子 1.38 | 参考项目的排版参数 |
| 一级标题 | 四号黑体、居中 | 参考项目的层级 |
| 封面 | 2026 文字标题及参赛信息，不显示页码 | 参照独立信息封面的结构重新实现 |
| 摘要与正文 | 摘要为第 1 页，后续连续编号，页脚居中 | 参考项目的摘要起始页编号 |
| 目录 | 默认关闭，可用 withtoc 开启 | 参考项目默认不推荐目录 |
| 公式、图、表、算法 | 按节重新编号，如 5.1、6.1 | 明确重置计数器，避免只改显示格式 |
| 附录 | A、B 分节，保留连续页码 | 字母附录与交叉引用 |
| 参考文献 | BibTeX + gbt7714-numerical | TeX Live 提供的 GB/T 7714-2015 顺序编码样式 |

这些参数是本模板的默认版式，**不是已经逐项核对的 2026 官方要求**。
官方入口：[竞赛主页](https://cpipc.acge.org.cn/cw/hp/4)。
2026 年度和届次依据：[参赛邀请函](https://cpipc.acge.org.cn/cw/contestNews/detail/4/2c9080189dcfa24e019dddacc24a1314?page=0)。

## 封面与匿名版本

`main.tex` 生成信息封面、标题摘要页、正文、参考文献和附录。
`anonymous.tex` 使用同一份内容，只省略信息封面。学校、队号、姓名不进入模板生成的摘要、页眉或 PDF 作者元数据。

此选项只控制模板自身的字段，不会扫描和删除正文、图片、文件附件或源代码中的身份信息；是否提交带封面的版本，应按当届通知决定。

当前封面不含往届 Logo。若主办方提供必须使用的封面页或图片，应依据正式文件调整，不要直接将往届年份改成 2026 后视为已合规。

## 章节与引用

正文使用 `\section`、`\subsection` 和 `\subsubsection`。
公式用 `\label` 与 `\eqref`；图片、表格、算法可用 `\figref`、`\tabref`、`\algorithmref`。
每节的计数器都会重新开始，附录中的编号形如 A.1。

表格标题写在表格上方，图片标题写在图片下方。
`longtable` 提供自动续页表头；`subcaption` 提供并列子图。
`amsthm` 提供定理与证明；`algorithm` 和 `algpseudocode` 提供伪代码。

参考文献标题由文献环境自动生成，不要再手工添加同名章节。
修改文献后使用 `latexmk` 自动执行 XeLaTeX / BibTeX 编译链。

## 示例与替换

示例由五个合成观测点构成，用于核对公式、表格、代码是否对应。
运行 `python code/fit_demo.py` 应输出斜率 2.0300、截距 -0.0900、RMSE 0.1349。
此误差是在拟合样本上计算的，不代表未知数据的预测能力。

正式写作时替换示例摘要、占位图、合成数据、程序和文献。
源程序通过 listings 排版，不在 LaTeX 编译期间执行。
