# 学术演示与复现说明

本项目正文以《基于NSGA-II的过期意大利面-42号混凝土低碳配合比优化》展示数学建模论文的完整组织方式，包括问题分析、体积配料、受约束多目标优化、代表方案、重复运行、敏感性分析和模型局限。案例由本项目构造，不对应官方赛题。

## 数据性质与适用边界

**所有数值响应、材料密度、碳排放因子、成本参数及其计算结果均为合成情景。** 没有真实材料试验数据、供应商报价或经核验的排放清单。“42号”仅为案例编号，不表示水泥标号或混凝土强度等级。

“过期意大利面”被设定为清洗、干燥和粉碎后的假想非结构材料添加物。文中的强度和坍落度是由假设公式生成的响应；达到约束值不能证明材料可用于实际工程。参考文献支持低碳材料与优化算法的研究背景，并不为本项目的合成系数提供实验依据。

功能单位为 `1 m³` 模型拌合物。碳排放与成本按六类材料用量乘以各自因子后求和，包括假设材料生产与添加物预处理；没有单独计入拌合能耗，也未计入运输、施工、服役、拆除、碳化吸收和避免废弃物处置收益。这是有限边界内的情景核算，不是完整或经认证的生命周期评价。

## 模型与算法

四个决策变量为胶凝材料总量 `B`、矿渣质量比例 `s`、有效水胶比 `r` 和干添加物用量 `P`：

| 变量 | 下界 | 上界 | 单位 |
| --- | ---: | ---: | --- |
| `B` | 300 | 460 | kg/m³ |
| `s` | 0 | 0.55 | 无量纲 |
| `r` | 0.32 | 0.52 | 无量纲 |
| `P` | 0 | 15 | kg/m³ |

水泥用量为 `(1-s)B`，矿渣用量为 `sB`，总水量为 `rB + 0.8P`。系数 `0.8` 是假设的吸水补偿系数，不是实测吸水率。粗骨料体积固定为 `0.38 m³`，含气体积固定为 `0.02 m³`，砂用量由绝对体积守恒计算。体积核算同时包括总水与干添加物体积；这种简化账目不等于已校准的多孔材料含水或饱和面干模型。

程序最小化碳排放、成本与负强度响应。演示约束为强度响应至少 `40 MPa`、坍落度响应 `140–220 mm`、总水量 `140–220 kg/m³`、砂用量 `500–1000 kg/m³`。强度、坍落度的具体响应式和所有系数保存在 [优化程序](../code/nsga2_demo.py) 与 [结果 JSON](../data/optimization_results.json) 的 `model` 字段中。

NSGA-II 使用约束支配关系、快速非支配排序、拥挤度、二元锦标赛、有界 SBX 交叉、多项式变异和父子代精英保留：

| 参数 | 设置 |
| --- | --- |
| 种群数、每代子代数 | 均为 80 |
| 初始化后的迭代代数 | 100 |
| 每次运行的候选评价次数 | `80 + 100 × 80 = 8080` |
| 随机种子 | 42、43、44、45、46；42 为主运行 |
| 随机数生成器 | NumPy `default_rng` / PCG64 |
| 每对父代交叉概率 | 0.9；触发后每个变量处理概率为 0.5 |
| 交叉、变异分布指数 | 均为 20 |
| 每个变量的变异概率 | 0.25 |
| 约束处理 | 可行解优先；不可行解比较归一化约束违反量 |

对照算法在相同变量区间独立均匀抽取 `8080` 个候选，保留可行非支配解；对照随机种子为对应 NSGA-II 种子加 `10000`。另设一个固定基准配比用于展示指标变化，它与均匀随机算法对照具有不同用途。

折中方案采用三个最小化目标的等权归一化距离选择。归一化的理想点与跨度取自主种子 42 的可行非支配解集，并固定用于其他种子和算法的折中比较。它是一种明确的偏好规则，不代表普遍唯一的最优选择。

算法质量以五次 NSGA-II 与五次随机对照结果合并后的非支配点作为经验参考，计算归一化 IGD。这个联合参考集不是已知真实 Pareto 前沿；IGD 较小仅说明相对于该有限参考集更接近，不能证明全局最优或算法在其他问题上同样占优。

## 如何解释当前结果

随附结果中，主运行折中方案的碳排放约为 `196.40 kg CO₂e/m³`，成本约为 `308.13 元/m³`，强度响应约为 `57.75 MPa`。相对固定基准配比，碳排放降低约 `32.97%`、成本降低约 `7.21%`，同时强度响应降低约 `3.35 MPa`。这些变化均由合成情景计算得到，不是实际减排、节约或材料性能的测定值。

折中方案的干添加物用量仅约 `0.027 kg/m³`，接近允许下界。假设响应直接对添加物设置了强度与坍落度损失，同时计入预处理碳排和成本，因此优化并没有为提高其用量找到足够的目标收益。结果不能用来声称“添加过期意大利面能够改善混凝土性能”，也不能将这个微小正数视为试验确定的有效掺量。它首先说明了目标函数和假设系数会怎样影响搜索方向。

敏感性分析固定名义折中方案的四个决策变量，分别进行以下复算：

- 将强度响应整体下调 5% 和 10%，检查与演示强度下限的距离。
- 将吸水补偿系数改为 0.4、0.8、1.2，调整总水并重新计算砂量以维持体积闭合。强度、坍落度未随该系数改变，是当前假设响应的结构所致。
- 将添加物单位碳排放因子改为 0.02、0.10、0.50 kg CO₂e/kg，比较总碳排变化。

这些检查没有对扰动后的情景重新优化，也不构成统计置信区间。低添加物用量使吸水与预处理因子的局部影响很小，不能据此推断高添加物情景也不敏感。折中方案的坍落度响应接近演示下限，实际工作性波动仍可能改变可行性。

后续真实研究需要先测定材料吸水与体积性质，获得强度、工作性和长期耐久性数据，明确预处理能耗及排放来源，再校准模型、评估不确定性并重新优化。现有论文与程序用于方法展示。

## 复现步骤

普通 LaTeX 编译使用随附 JSON 派生的表格和图片，无需 Python。仅查看论文时，在根目录执行 `latexmk main.tex`；内部审阅版本使用 `latexmk anonymous.tex`。

重新计算和生成全部论文图表时，在项目根目录执行：

```bash
python -m pip install numpy matplotlib
python code/nsga2_demo.py --check
python scripts/prepare_paper.py
latexmk main.tex
latexmk anonymous.tex
```

优化程序依赖 NumPy 和 Python 标准库，绘图与表格脚本另需 Matplotlib。Python 与 NumPy 的实际版本记录在结果 JSON 的 `software` 字段中；固定种子保证同一运行环境内的可重复检查，跨版本比较应保留环境信息并检查数值差异。

`--check` 除重新计算全部结果外，还检查已知约束排序算例、拥挤度算例、主解集的变量边界与约束、两两非支配性、体积闭合，以及种子 42 的完整重复运行。完整重复运行额外执行 `8080` 次候选评价，其开销单独记录，不计入每次算法对照的 `8080` 次预算；报告阶段对已有方案的重新计算同样不计入搜索预算。

| 文件 | 内容 |
| --- | --- |
| `code/nsga2_demo.py` | 合成情景、NSGA-II、随机对照、指标、敏感性和自检 |
| `data/optimization_results.json` | 完整模型参数、算法设置、主解集、代表方案、重复运行统计、敏感性与检查结果 |
| `data/pareto_front.csv` | 主随机种子的非支配方案及配料、响应、目标和折中距离 |
| `data/run_summary.csv` | 五次 NSGA-II 和五次均匀随机对照的汇总 |
| `scripts/prepare_paper.py` | 从 JSON 生成正文数值、表格和图片 |
| `data/paper_values.tex` | 正文引用的数值宏 |
| `data/*_table.tex` | 正文使用的结果表格 |
| `figures/pareto.pdf`、`.png` | Pareto 取舍与代表方案 |
| `figures/convergence.pdf`、`.png` | 主运行迭代历史与五次 IGD 对照 |
| `figures/sensitivity.pdf`、`.png` | 固定折中与最低碳方案的强度扰动、折中方案碳因子检查 |

如修改合成参数或算法设置，应依次重新计算、生成图表并编译，同时核对摘要、结果解释和本说明中的数值。无需修改模型时，直接使用随附成果即可。
