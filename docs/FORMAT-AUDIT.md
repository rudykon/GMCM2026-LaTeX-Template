## 附件 2 对照

| 官方要求 | 实现与边界 |
| --- | --- |
| 从 A、B、C、D、E、F 中任选一题 | `config.tex` 保留题号设置，默认 A；附件 3 封面没有题号栏，因此不印在封面 |
| 题目、摘要和关键词写在摘要页；下一页开始正文 | `\maketitle` 与 `abstract` 排版摘要页，末尾换页；目录默认关闭 |
| 从摘要页以阿拉伯数字 1 连续编号，页码在每页页脚中部 | 封面不编号，摘要重置为 1；正文、参考文献和附录连续编号 |
| 不能有页眉，不能出现可能显示答题人身份的标志 | 不生成页眉，PDF 作者字段留空；附件 3 指定的身份字段仅用于封面，正文、图像及程序内人为写入的信息需自行检查 |
| 论文题目三号黑体、一级标题四号黑体，并居中 | 类文件统一设置 |
| 其他汉字一律小四宋体，单倍行距 | 正文、二级及以下标题、中文图表文字按此设置；`\setstretch{1}` 实现 LaTeX 单倍行距 |
| 摘要包含建模思路、主要方法、模型、结果与结论、创新点、关键词 | 示例摘要给出写作提示；实际内容由作者负责 |
| 摘要“篇幅一般不超过两页，且无需译成英文” | 不生成英文摘要，不截断长摘要；超过两页时给出提醒 |
| 公开资料在正文引用处和文献表中列明；引用程序注明来源 | 文档提示适用于网络、博客和源程序；模板不能自动核验来源是否完整 |
| 方括号引文，文献按正文引用次序排列；引用书籍指出页码 | natbib 数字方括号，BibTeX 样式按首次引用排序；书籍支持引用页段，缺少页码时由格式检查提示 |
| 书籍：作者，书名，出版地：出版社，起止页码，出版年 | `gmcm-numerical.bst` 的 `book` 类型 |
| 期刊：作者，论文名，杂志名，卷期号：起止页码，出版年 | `article` 类型 |
| 网页：作者，资源标题，网址，访问时间（年月日） | `misc` / `online` / `webpage` 类型，`urldate` 填 `YYYY-MM-DD` |
| 如赛题要求，在规定时间内上传结果和编程源程序 | 使用说明保留这一条件；代码附录不能代替上传 |

“一般不超过两页”保留原文的限定。附件 2 未给出页边距、公式编号、图表编号、统一上传时刻、提交文件名或文件类型；这些事项不能从往届公告推定为本届规定。

## 附件 3 对照

附件 3 从旧版 `.doc` 转换后读取文本、字体和页面属性，并提取原始图形。封面含中国研究生创新实践系列大赛、研究生数学建模竞赛、华为、西安交通大学四个 Logo。模板直接使用原始图形资源；学校、参赛队号、三位队员姓名由 `config.tex` 或 `config.local.tex` 填入，不再添加原件没有的“选择题号”、独立年份或“参赛论文”标题。

Logo 显示框和正、负裁剪参数取自附件内嵌图形；图形间距、行位置按转换页测量，保留自然尺寸。第二个 Logo 的 RGB 像素已逐字节核对，与原始 PNG 一致；它采用 DeviceRGB 且不带冗余透明蒙版，以改善阅读器兼容性。转换页的空格可能涉及字体替代，因此不将测得位置视为 Microsoft Word 的逐像素保证。

按本示例的定制要求，学校、参赛队号、队员姓名三个标签等宽对齐，姓名在填写栏居中；第三位队员下方横线延长至与参赛队号横线等长、两端对齐。这条末线比附件 3 的原始末线更长。

封面和摘要页的系列赛事标题使用 18 pt、赛事名称使用 22 pt 的华文新魏；摘要页“题目”“摘要”“关键词”标签使用 18 pt 隶书。正文题目、各级标题及正文遵守附件 2；这些前置页面的装饰字样参照附件 3。缺少对应字体时采用已说明的替代字体。

| 页面属性 | 附件 3 转换值（twip） | 模板采用值 |
| --- | --- | --- |
| 纸张 | 11906 × 16838 | A4 |
| 上边距 | 1702 | 约 30 mm |
| 下边距 | 1048 | 参数 18.5 mm，含页脚；正文区域另留 8 mm 页脚间距 |
| 左、右边距 | 1276、1274 | 约 22.5 mm |
| 页脚距离 | 992 | 原件约 17.5 mm；LaTeX 采用 `includefoot,footskip=8mm` |

转换后的 Word 封面可能显示页码 0。附件 2 明确从摘要页的 1 开始编号，因此本模板封面不显示页码，摘要为 1。Word 页脚距离与 LaTeX 的 `footskip` 度量基准不同，不能直接使用相同数值代换。为页码留足空间，正文下边界约距纸张底部 26.5 mm，页脚基线约距底部 18.5 mm，不声称与 Word 正文区域完全一致。空白段落遗留样式与附件 2 不一致时，也以附件 2 的明确文字要求为准。

正式稿使用带封面的 `main.tex`；`anonymous.tex` 仅供内部审阅。若需导入在 Word 中填写完成的封面，仍可使用 `cover-pdf`，方法见 [官方封面说明](../official/README.md)。

## 编译验证与边界

默认正文保持简短，保留公式、流程图、结果占位表、合成数据插图和文献引用。带封面版本 `main.pdf` 共 5 页，内部审阅稿 `anonymous.pdf` 共 4 页，含摘要、参考文献与短代码附录。两个入口的编译、成品、文献和版式检查均已通过：

```bash
latexmk
latexmk anonymous.tex
python scripts/check_build.py
python scripts/check_bibliography.py
python scripts/check_layout.py
```

`check_build.py` 检查页面尺寸、摘要起始页码、连续页码、作者元数据、引用解析及排版溢出；`check_bibliography.py` 检查三类著录格式、引用顺序与缺少书籍页码时的提示。`check_layout.py` 使用临时文档检查原生和导入封面、四个 Logo、页边距、长题目换行、两页与超长摘要、内部稿目录，以及字体自动选择和显式选项。

默认模板不加载 `data/paper_values.tex` 或优化结果表格，仅引用随附的 `figures/pareto.pdf` 作为插图示例；完整优化演示保留为可选资源，见 [演示说明](DEMO.md)。模板字体设置为论文题目 16 pt SimHei、一级标题 14 pt SimHei、正文 12 pt SimSun；前置页使用 STXinwei 和 LiSu，西文使用 Times New Roman。带封面与无封面版本的摘要及后续内容、页码应一致；`docs/preview.pdf` 为带封面版本。

初次编译验证了跨平台替代字体；随后已在本机安装 SimSun、SimHei、STXinwei、LiSu 和 Times New Roman，并重新通过成品与版式检查。字体均已嵌入 PDF，没有缺字、字体样式缺失或排版溢出。安装位置与来源见 [字体记录](FONTS.md)。自动检查不能证明正文完全匿名、引用充分或论文内容满足赛题要求。

系统有宋体、黑体时优先使用，否则回退到 Fandol；华文新魏、隶书也设有替代字体。替代字体的字形与原件存在差异，LaTeX 与 Word 的字体度量也会影响换行。正文和摘要页需要结合生成的 PDF 检查，不能仅凭源码参数认定逐像素一致。
