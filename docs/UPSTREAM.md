# 参考项目与实现来源

参考项目版本于 2026-09-15 记录，格式依据于 2026-09-16 更新为本地提供的当届附件 2、附件 3：

| [andy123t/GMCMthesis](https://github.com/andy123t/GMCMthesis) | `80613e086799143ecd44ae929e28abce46fec428` | 封面页码修复、字体适配、表格和代码附录用法 |

两者共享 GMCMthesis 项目沿革；latexstudio 的更新记录也列出了对 andy123t 改动的合并。

本仓库采用独立编写的 `gmcm2026.cls` 和 `gmcm-numerical.bst`。参考上述项目的结构和使用方式，不直接复制其类文件、文献样式或示例论文。2026 格式核对以 `docs/` 中的两份附件为依据。依赖由 TeX Live / MiKTeX 安装，不将发行版宏包改署为本仓库作品。

具体调整：

- 年份、届次、学校、队号和队员信息改为集中配置。
- 提供独立匿名入口，身份字段只用于封面，PDF 作者元数据留空。
- 正确重置按节编号的计数器，支持字母附录及可选目录。
- 优先使用系统宋体、黑体；缺少时回退到 Fandol，装饰字体也提供替代方案。
- 从附件 3 提取当届四个 Logo，封面字段和摘要结构对齐当届模板。
- 独立实现附件 2 中书籍、期刊和网页的著录顺序，支持书籍的正文引用页码和文献页段。
- 以明确标注的合成材料模型和 NumPy 实现的 NSGA-II 演示复现，公开对照结果与绘图程序，不复用上游赛题正文。
- 增加跨平台构建入口与 GitHub Actions 编译检查。

当届文字规范优先于参考项目的默认参数：正文采用单倍行距，小四宋体；题目和一级标题按规定使用三号、四号黑体。封面与摘要页依据当届附件 3，实际实现及字体替代见 [核对记录](FORMAT-AUDIT.md)。
